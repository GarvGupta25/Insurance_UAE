# Public source registry

The initial read-only registry contains [Daman's individual health overview](https://www.damanhealth.ae/) and [ADNIC's medical insurance page](https://www.adnic.ae/web/guest/medical-insurance). These are official pages, but no live premium, exact eligibility, network membership or current contractual term has been approved from them. The three purchasable sandbox plans remain entirely fictional and separate. The quote and PDF do not borrow real insurer identity or terms.

`backend/data/source_registry.json` is an administrator-controlled allowlist. From `backend/`, run `uv run python -m scripts.refresh_sources` after applying the second migration. The job retrieves public HTML/PDF only from the exact approved HTTPS host, rejects redirects, credentials, non-public DNS answers, oversized/unsupported content and remote errors, then stores an append-only hash and a bounded plain-text excerpt in `source_snapshots`. A failed refresh retains the last version and does not change a quote. The app's `/api/sources` endpoint shows the approved links, retrieval date and unreviewed status. Raw page instructions are never executed or added to a model prompt.

Before any real product appears in comparison, an administrator needs to review the brochure/page, enter each material fact with its source location and effective date, confirm current availability, obtain a legitimate pricing route, and separately version any provider network. Until then, use these links only for independent research. Refresh product pages weekly and directories monthly when those sources are approved; verify prices and availability at selection when a carrier offers a supported integration. A source page change does not amend an issued policy snapshot or authorize a new quote term.
